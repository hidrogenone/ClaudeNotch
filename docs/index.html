Install in 30 seconds

  1. Download ClaudeNotch.zip from the latest release.
  2. Unzip and move ClaudeNotch.app to Applications.
  3. Right-click → Open (ad-hoc signed). If macOS complains: xattr -dr com.apple.quarantine /Applications/ClaudeNotch.app
  4. Look for the ✓ in your menu bar. Try Test Alert.
